Why

The stock LG Magic Remote is oversized for what most TV use looks like: move focus, press OK, press Back. The Boxput BPR1S Plus is the opposite - a small, light remote with d-pad and a few shape buttons, comfortable in one hand. Out of the box, webOS ignores its dongle. This app maps exactly the keys that matter (Home, OK, Back, Menu) and lets the small remote replace the big one for daily use - same launcher, same apps, no giant remote on the couch table. The dongle's gyro pointer keeps working untouched for the rare pointer moments.

What it does

The Boxput BPR1S Plus 2.4 GHz USB remote sends Home, OK, Back and Menu as keycodes webOS ignores. This service maps them: Home and Menu open the launcher, OK sends ENTER, Back sends the real Back key (keyCode 461, the same path LG's phone remote uses). Every other key passes through unchanged.

Requirements

  • Rooted LG webOS TV with Homebrew Channel
  • 32-bit soft-float userland (webOS 5 and 6). TVs with a 64-bit userland are not supported
  • Boxput BPR1S Plus with USB dongle

How it runs

A single static binary, about 50 KB, one thread, nice -n 19. It opens only the dongle's keyboard event nodes, read-only, and never grabs them, so the remote keeps working when the service stops. It blocks in epoll and stays at 0% CPU while idle. Autostart is installed on the first launch through the Homebrew Channel service and removed with the app.
